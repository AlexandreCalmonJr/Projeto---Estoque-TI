Importar Ativos de Arquivo

Selecione um arquivo CSV ou Excel (.xlsx) para importar múltiplos ativos de uma vez.

Instruções e Formato do Arquivo

O arquivo deve conter um cabeçalho com os nomes das colunas. As colunas essenciais são:

  • ATIVO ou categoria (Obrigatório)
  • FABRICANTE ou marca (Obrigatório)
  • MODELO (Obrigatório, pode ser genérico)
  • Nº SERIE ou numero_serie (Opcional)
  • QUANTIDADE (Opcional, padrão '1')

Atenção: Se o "Nº SERIE" não for fornecido, o sistema gerará um serial provisório. Se a `QUANTIDADE` for maior que 1, o sistema criará a quantidade correspondente de itens com seriais únicos.
